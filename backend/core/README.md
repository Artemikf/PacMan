## score_manager.py 
***Очки, жизни, рекорд***

***add_points(pts)*** — единственное место где меняется ***self.score***. Сразу проверяет рекорд и сохраняет его. DRY — все методы вызывают ***add_points***, не меняют score напрямую.

***add_ghost_eaten()*** — каждый последовательно съеденный призрак удваивает очки: первый 200, второй 400, третий 800, четвёртый 1600. Это достигается через ***2 ** (self._ghost_combo - 1)***. Комбо сбрасывается в ***add_energizer()*** и ***lose_life()***.

***_load_high_score*** / ***_save_high_score*** — читают/пишут ***high_score.json***. try/except защищает от испорченного файла или прав доступа. Path из модуля pathlib способ для работы с путями.
