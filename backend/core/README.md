## score_manager.py 
***Очки, жизни, рекорд***

***add_points(pts)*** — единственное место где меняется ***self.score***. Сразу проверяет рекорд и сохраняет его. DRY — все методы вызывают ***add_points***, не меняют score напрямую.

***add_ghost_eaten()*** — каждый последовательно съеденный призрак удваивает очки: первый 200, второй 400, третий 800, четвёртый 1600. Это достигается через ***2 ** (self._ghost_combo - 1)***. Комбо сбрасывается в ***add_energizer()*** и ***lose_life()***.

***_load_high_score*** / ***_save_high_score*** — читают/пишут ***high_score.json***. try/except защищает от испорченного файла или прав доступа. Path из модуля pathlib способ для работы с путями.

## game_map.py 
***Сетка тайлов, точки, фрукты***

***BASE_MAZE*** - список из 22 строк, каждая — список из 21 числа. 0=стена, 1=точка, 2=энерджайзер, 3=пустота, 4=дом призраков, 5=место фрукта. Это константа — шаблон который копируется при каждом новом уровне

Vec2 — двумерный вектор. Используется везде для координат. Методы:

- ***__add__*** — оператор + для сложения векторов (движение: позиция + скорость * dt)

- ***distance_to*** — евклидово расстояние через теорему Пифагора, нужно для определения столкновений

- ***to_grid(tile_size)*** — переводит пиксельные координаты в индексы сетки: ***row = int(y // tile_size)***. Целочисленное деление — определяем в каком тайле находится объект

- ***from_grid(row, col, tile_size)*** — обратное: центр тайла в пикселях: ***x = col * tile_size + tile_size // 2***
