## pacman.py 
***Движение, рот***

Направления как ***Vec2*** — ***DIR_RIGHT = Vec2(1, 0)***, ***DIR_UP = Vec2(0, -1)*** (ось Y в Pygame направлена вниз, поэтому вверх = -1). Это константы модуля, не атрибуты класса — их можно импортировать и использовать везде.

***set_direction(direction)*** — не меняет направление сразу, а сохраняет в ***_queued_dir***. Реальное изменение происходит в ***_try_turn*** при обновлении. Это нужно чтобы можно было нажать поворот чуть раньше поворота — игра запомнит намерение.

_try_turn(game_map) — если запрошенное направление отличается от текущего, проверяет _can_move_in. Если можно — меняет направление.

_can_move_in(direction, game_map) — проверяет тайл на полтайла вперёд в запрошенном направлении: test_x = self.position.x + direction.x * ts * 0.5. Возвращает not game_map.is_wall(row, col).

_move(dt, game_map) — вычисляет step = speed * dt, добавляет к позиции, проверяет стену в новой позиции. Тоннельный перенос: если x < 0 → переходит на правый край, если x >= ширина → на левый.

_animate_mouth(dt) — анимация через фазу синуса. _anim_time накапливается. Период одного цикла (открыть+закрыть) = 1/MOUTH_ANIM_SPEED секунд. Фаза определяет текущий угол раскрытия рта от 0 до 45 градусов.

rotation_deg — свойство (property) которое возвращает градусы поворота спрайта в зависимости от направления. Renderer использует это чтобы правильно нарисовать открытый рот в нужную сторону.
