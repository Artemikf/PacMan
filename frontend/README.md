
`_hex_to_rgb` - перетворює «#1a2b3c» на (26, 43, 60). 
Видаляє символ #, бере символи попарно, перетворює з hex у int. Це потрібно, оскільки Pygame використовує RGB-типи, а конфігураційний файл зберігає hex-рядки

- `_init__` - ініціалізує константи(розмір вікна, карти, колір)
- `init_screen` - відкриває вікно гри, задає потрібний розмір, стоврює заголовок
- `draw_game` - основний метод створення кадру. Порядок має значення: спочатку заливка фону, потім лабіринт, потім точки, потім фрукт, потім Пакман, потім привиди, потім HUD. Кожен наступний шар малюється поверх попереднього
- `draw_menu` - показує назву, кнопку запуску, запис, підказки щодо керування
- `draw_pause` - меню паузи
- `draw_game_over` - меню програшу
- `draw_victory` - меню виграшу
- `_draw_maze` - отримує екран (surface), отримує карту (game_map), проходить по всіх клітинках, малює елементи лабіринту та будинок привидів
- `_draw_dots` - малює крапки та бонусні крапки(поінти)
- `_draw_fruit` - малю фрукти
- `_draw_pacman` - визначає позицію, радіус, кут розрізу та кут повороту. 
Викликає `_draw_pacman_arc` — статичний метод, який малює заповнений сектор


- `_draw_pacman_arc` - генерує список точок: центр та точки на окружності з кроком 3 градуси. 
`pygame.draw.polygon` малює заповнений багатокутник. Око малюється окремим колом із невеликим зміщенням під кутом 70° від напрямку
- `_draw_ghost` - отримує екран (surface), отримує об’єкт привида (ghost), малює його
- `_draw_ghost_eyes` - промальовка очей
- `_draw_hud` - темна смуга зверху, три текстові поля (score, highscore, level) та маленькі іконки Пакмана для життів за допомогою того самого `_draw_pacman_arc`
